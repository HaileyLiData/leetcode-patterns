# LeetCode Patterns

Learning coding interview problems by pattern: [LeetCode 75](https://leetcode.com/studyplan/leetcode-75/) first, then [NeetCode 150](https://neetcode.io/practice).

Each problem goes through three passes: understand the solution → write it from memory → solve it under a time limit.

- [solutions.md](./solutions.md): all solutions, grouped by category, each with the key idea, common mistakes, and complexity
- [patterns.md](./patterns.md): one page per pattern, with a code template, the signals that point to it, how each problem varies from the template, and my own thought process

Notes in the code and in patterns.md are mostly in Chinese.
